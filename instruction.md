# Restaurant Website Clone Instructions

## Your Job
This project folder contains a copy of an existing restaurant website built with React, Tailwind CSS, and HTML. Your job is to replicate the entire website for a new restaurant — keeping everything identical except the content the user provides below.

## What to Change
Replace only the following with the new restaurant's information:

- Restaurant name — everywhere it appears (navbar, hero, footer, page title, meta tags)
- Address — footer, contact section, map link if any
- Phone number — footer, contact section
- Email — footer, contact section
- Menu items and prices — match the existing menu structure, just replace item names and prices

## What NOT to Change
- Design, layout, or structure of any component
- Colors, fonts, or typography
- Spacing, padding, or margins
- Images (unless user provides new ones)
- Animations or interactions
- File structure or component names

## How to Start
1. Read all existing files first to understand the structure
2. Identify where the restaurant name, address, phone, email, and menu data are written
3. Replace only those values with what the user has provided
4. Do not rewrite or refactor any code — only change the content values
